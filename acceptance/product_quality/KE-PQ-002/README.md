## Confirmed code behavior versus case hypotheses

Synthetic characterization establishes that incidental marketing terms can reverse
ranking, repeated constraints increase weight despite an unchanged query, weak
matches permit generation, empty evidence blocks dispatch, and single-source
knowledge answers can retrieve zero-overlap assets. It also establishes one cited
member crediting both materials in a consolidated group, while reporting zero used
ideas for the normal prepared shape. The counting code reads top-level `asset_id`,
but normal groups provide `canonical_asset.id`. Earlier diagnostics assumed a
normalized shape used by older test fixtures and missed this mismatch. These tests demonstrate mechanisms, not the historical cause of this output.

`knowledge_answer` uses a dedicated provider schema and coverage metadata;
`research_synthesis` uses general artifact output and gap instructions. Neither
has a general semantic sufficiency gate. Valid references are provenance checks,
not entailment or research-completeness proof. The exact model interpretation,
missed direct evidence, ranking displacement and historical citation inflation
remain hypotheses until actual runtime records are available.

## Proposed acceptance requirements — NOT implemented

1. Concise and long equivalent research briefs retain directly relevant evidence;
   incidental commercial context must not crowd it out. Evaluate with labeled
   direct, partial and distractor assets and a declared retrieval limit.
2. Repeating instructions/constraints alone must not increase substantive relevance.
   Preserve valid constraints and explicit scope controls.
3. Both modes disclose weak/partial research coverage at the affected question or
   claim, without disguising generic advice as established psychology. Empty
   evidence continues to block dispatch. Preparation completeness is distinct.
4. Exact member citations credit the member's source; whole-group support must be
   explicitly distinguishable. One consolidated idea may legitimately have several
   sources, but only actually referenced evidence should increase cited counts.
   A cited normal group must count as one used idea rather than zero.
5. Selected, retrieved, applied and section-cited counts are separately defined;
   legacy fallbacks must not describe merely retrieved ideas as verified grounding.
6. Research synthesis and knowledge answers expose comparable scope limitations
   while retaining their different artifact formats and uncertainty treatment.
7. Existing validation, snapshot identity, source boundaries, lifecycle history,
   free-tier gates and provider-attempt limits remain intact. No semantic repair,
   paid fallback or additional provider calls are introduced.

Human acceptance must separately assess depth and claim/evidence support. These
requirements need product review; they are not a speculative scoring algorithm.

## Smallest implementation options — proposals only

- First use the canonical ID from the actual prepared group shape for idea counts,
  clarify count labels and track member-to-source identity through coverage
  accounting; keep group support distinct from exact citation support.
- Expose matched terms and score contributions in diagnostic records so ranking
  failures can be reproduced without regenerating outputs.
- Evaluate deduplicating repeated constraints/brief signals using labeled fixtures
  before changing ranking weights or introducing any query decomposition.
- Give research synthesis explicit structured scope/gap reporting, without claiming
  that a deterministic lexical score proves semantic sufficiency.

Do not change retrieval wholesale or add model-based sufficiency calls on this evidence.

## External beta decision

Block presenting this workflow as validated comprehensive research or citing source
counts as verified independent support. The supplied output and synthetic tests do
not establish that promise. A limited supervised beta can proceed only with explicit
coverage limitations and human evidence review; this case alone is not a demonstrated
blocker for unrelated manual import, storage or nonresearch workflows. Resolve exact
citation accounting before relying on multi-source counts as an acceptance metric.
