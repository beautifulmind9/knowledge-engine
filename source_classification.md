# Source Classification

## Purpose

Not all books should be analyzed the same way.

The system should classify each source using multiple tags so the extraction questions can adapt to the source.

---

# Classification Layers

## 1. Form

What kind of source is it?

Examples:

- Academic book
- Nonfiction book
- Novel
- Textbook
- Manual
- Research paper
- Report
- Memoir
- Essay collection
- Speech transcript

## 2. Domain

What broad field does it belong to?

Examples:

- Writing
- Communication
- Public Speaking
- Finance
- Investing
- Economics
- Psychology
- Product
- Strategy
- Leadership
- Policy
- Technology
- Fiction
- Memoir

## 3. Subdomain
